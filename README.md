# gesture_AI

gesture_AI는 수어 동작을 실시간으로 인식하고, 인식된 단어 후보를 자연스러운 한국어 문장으로 변환하는 AI 기반 수어 번역 서버입니다.

## 프로젝트 개요

본 프로젝트는 수어 사용자의 손동작을 키포인트 데이터로 변환한 뒤, 딥러닝 모델을 통해 수어 단어를 예측하고, 예측된 단어들을 자연스러운 한국어 문장으로 복원하는 것을 목표로 합니다.

서버는 FastAPI 기반으로 구현되었으며, WebSocket을 통해 실시간 키포인트 데이터를 수신합니다. 수신된 데이터는 PyTorch 기반 BiGRU 모델에 입력되어 수어 단어로 분류됩니다. 이후 인식된 단어 후보들은 Ollama 기반 로컬 LLM을 통해 자연스러운 한국어 문장으로 변환됩니다.

또한 Faster-Whisper 기반 STT 기능을 함께 제공하여 음성 스트림을 실시간 텍스트로 변환할 수 있습니다.

## 핵심 기능

### 1. 실시간 수어 인식

클라이언트에서 추출한 키포인트 데이터를 WebSocket으로 수신하고, 일정 프레임 단위로 수어 단어를 예측합니다.

입력 데이터는 손과 어깨의 좌표 정보를 포함한 88차원 키포인트 벡터이며, 30프레임 단위의 시퀀스로 구성되어 모델에 전달됩니다.

### 2. BiGRU 기반 수어 단어 분류

88차원 키포인트 시퀀스를 입력으로 받아 BiGRU 모델을 통해 수어 단어 클래스를 분류합니다.

양방향 GRU를 사용하여 손동작의 시간적 흐름을 학습하고, 마지막 time step의 출력을 기반으로 최종 단어 클래스를 예측합니다.

### 3. 입력 프레임 검증

수신한 키포인트 데이터가 정상적인지 검증합니다.

프레임 크기, NaN 또는 Infinity 여부, 손 랜드마크의 중복 정도, 어깨 좌표 간 거리 등을 확인하여 잘못된 입력 데이터를 필터링합니다.

### 4. 예측 안정화

모델의 softmax 결과에서 Top-K 후보 단어를 추출하고, confidence threshold를 기준으로 신뢰도가 낮은 예측을 제외합니다.

또한 최근 예측 결과를 기반으로 majority voting을 적용하여 순간적인 오분류를 줄이고 안정적인 단어 예측을 수행합니다.

### 5. 문장 종료 감지

사용자가 손을 내리거나 일정 시간 동안 유효한 수어 동작이 감지되지 않으면 문장이 끝난 것으로 판단합니다.

이를 통해 단어 단위 예측 결과를 문장 단위로 묶어 처리할 수 있습니다.

### 6. 로컬 LLM 기반 문장 복원

수어 인식 모델이 예측한 단어 후보들을 Ollama 기반 로컬 LLM에 전달하여 자연스러운 한국어 문장으로 변환합니다.

단어 후보를 단순히 나열하는 것이 아니라, 문맥상 가장 적절한 단어를 선택하고 필요한 조사와 어미를 보완하여 최종 문장을 생성합니다.

Ollama 모델이 설정되어 있지 않거나 호출에 실패한 경우에는 1순위 후보 단어를 연결하는 fallback 방식을 사용합니다.

### 7. 실시간 STT 기능

별도의 WebSocket 엔드포인트를 통해 음성 데이터를 수신하고, Faster-Whisper 모델을 사용하여 한국어 음성을 텍스트로 변환합니다.

오디오 스트림을 일정 간격으로 추론하여 변경된 텍스트를 클라이언트에 전달합니다.

### 8. 서버 상태 확인

루트 경로와 health check API를 통해 서버가 정상적으로 동작하는지 확인할 수 있습니다.
